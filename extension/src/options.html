Normally the first sync merges this browser with the server: links that are on both sides stay single, the rest is added on both sides, and nothing is deleted. If that is not what you want:
The first replaces this browser's synced bookmarks (toolbar, other, mobile) with what the server has. The second empties the server's profile and uploads this browser's bookmarks; other devices of the profile then follow. The server keeps a copy that can be restored in its web UI under Profiles.
